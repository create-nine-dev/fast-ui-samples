# Fast UI Samples --- Service Case

A sample application demonstrating how **Fast UI** can be used to build
a modern enterprise service-case experience.

This sample is part of the `fast-ui-samples` repository and focuses on
bringing reusable Fast UI components together in a realistic application
scenario.

## Sample

### Service Case

The `svc-case` sample demonstrates a service-case application with an
enterprise-oriented UI, including areas such as:

-   Case overview
-   Customer and case information
-   Forms and structured data
-   Tables and related records
-   Dialogs and user actions
-   Reusable Fast UI components

The purpose of this sample is to demonstrate **how the components work
together in an application**, rather than showing each component in
isolation.

## Getting Started

Install the dependencies:

``` bash
npm install
```

Start the development server:

``` bash
npm run dev
```

The application will be available at the local URL shown by Vite.
